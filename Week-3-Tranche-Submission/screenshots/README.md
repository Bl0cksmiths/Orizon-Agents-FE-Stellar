# Screenshots — evidence manifest (Week 3)

**Status: all 20 public-web shots captured (2026-09-26, 19:48–19:50 PHT /
11:48–11:50 UTC).** Every frame is a full-page PNG of a public page taken by
Playwright Chromium in a 1440×900 viewport, and every PNG was opened and looked
at by eye after capture. Each row below carries the source URL so a reviewer can
check the same page live.

**No wallet was connected. Nothing was signed, authorized, paid or submitted.**
The capture script makes exactly one write-shaped request — shot #15's
`POST /api/disputes/{id}/uphold` — and that request is refused by the deployment
with `503 dispute_refunds_disabled` before it touches money. The refusal is the
evidence.

**Two frames are not Deliverable-3 evidence.** Shots #16 and #17 are QA's drill
transactions. They are real and successful on Stellar testnet, but they were
signed on a developer machine by source account `GA45IT…RJEGZ2`, which is **not**
the deployment's signer (`GDB4N25U…CDHP`, per #13), against a drill
ReputationLedger (`CAFZ…5CRP`, not the deployment's `CDCS…22ZT` from #12) and a
test asset (`CCW6…UENL`, not the deployment's asset SAC `CDLZ…CYSC`). They prove
the code path executes on chain. They are not, and must not be presented as, the
Deliverable-3 dispute-refund evidence.

**Cropping.** Where a page runs for tens of thousands of pixels below the panel
that is the evidence, the full-page shot is clipped from the top and the row says
so. Nothing is cropped from the middle, and no crop removes a caveat. Every frame
is re-encoded with a 256-colour adaptive palette (no dithering, no resizing) so
the assembled PDF stays under 10 MB; resolution and pixel positions are unchanged
and text is byte-identical at 1:1.

## Reproduce

```bash
node Week-3-Tranche-Submission/screenshots/capture-screenshots.mjs        # all 20
node Week-3-Tranche-Submission/screenshots/capture-screenshots.mjs 01 15  # just some
```

The capture script never connects a wallet, authorizes, simulates or pays. It
wakes the Render backend before the first shot needs it — measured cold at 63 s
earlier in this session, and already warm by the time the run started — and
retries each shot once with doubled waits. It writes `capture-meta.json` beside
the PNGs recording each frame's source URL, capture time, original page height,
crop height and byte size — that file is where this manifest's numbers come from.

Requires Chromium's system deps (one-time, needs sudo in a real terminal):
`sudo apt-get install -y libnspr4 libnss3 libasound2t64` — or
`npx playwright install-deps chromium`. The size pass needs Python's Pillow.

Files in this folder prefixed `local-` are captured by a separate local-UI pass
and are not covered by this manifest.
